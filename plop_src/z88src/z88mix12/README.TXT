   The features of the Z88 Windows version match exactly the UNIX version.

1) Copy the self-extracting file Z88RUNE.EXE into a new or existing
   directory of your choice, e.g. C:\Z88 

2) Launch Z88RUNE.EXE, e.g. by > Start > Run. 
   If this will not work, unzip Z88RUNE.ZIP.
   
   The Z88 executables, the samples, the online-help files and the header
   files are extracted into the directory 1). That's all ! The Windows
   system files are not altered in any way.

   Some Windows versions like XP and 2000 require to release the read-only
   attributes: use attrib -R *.* for all Z88 files in a command prompt
   window or mark all Z88 files within the Windows explorer, right mouse
   button, > properties, take away the read-only mark, > OK
 
3) Now you may delete Z88RUNE.EXE from your directory to avoid a later
   execution by accident.

4) Z88 is now ready to run. You can launch Z88 immediately by starting
   the Z88-Commander Z88COM. But stop ! First, install the online help
   system and put a link to Z88 onto your desktop. How to do? Consult the
   manual chapter 1.2 "How to install Z88" in the Z88 manual Z88MANE.PDF
   or open the file e88mrw.htm with any Internet browser. 

5) You should consult the manual, chapter 1.1 "General Overview FEA
   Program Z88" in Z88MANE.PDF for a first overview.

6) Now proceed with the first example "Fork Wrench with Plane Stress
   Ele.7", chapter 5.1.
